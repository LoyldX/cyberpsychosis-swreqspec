## รายการ task

### T-01 สร้างโครงข้อมูล session ใน Redis
- รองรับ: FR-AUTH-01, CON-CACHE-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง FR-AUTH-01 แทน)
- ไฟล์ที่แตะ: `backend/app/models/session.py`, `backend/app/repositories/session_store.py`, `backend/tests/test_auth_session.py`
- ต้องทำหลัง: โครงโปรเจกต์ (ดูหมายเหตุ 001)
- เสร็จเมื่อ: สร้าง session แล้วมี key ใน Redis และอ่านกลับได้
- สถานะ: รอการตัดสินใจทีม: โครงโปรเจกต์ (ดูหมายเหตุ 001); รอการตัดสินใจทีม: วิธีรัน Redis สำหรับ test; รอการตัดสินใจทีม: เจ้าของข้อมูลสมาชิก (`member_id`)

### T-02 สร้างการเข้าสู่ระบบและออก refresh token
- รองรับ: FR-AUTH-01, CON-CACHE-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง FR-AUTH-01 แทน)
- ไฟล์ที่แตะ: `backend/app/api/auth.py`, `backend/tests/test_auth_session.py`
- ต้องทำหลัง: T-01
- เสร็จเมื่อ: สมาชิกที่เข้าสู่ระบบสำเร็จได้รับ refresh token และ session ถูกเก็บใน Redis
- สถานะ: รอ Q2; รอ Q7; รอการตัดสินใจทีม: วิธีเข้าสู่ระบบของสมาชิก; รอการตัดสินใจทีม: วิธีรัน Redis สำหรับ test; รอการตัดสินใจทีม: เจ้าของข้อมูลสมาชิก

### T-03 สร้าง endpoint ต่ออายุ session ด้วย refresh token
- รองรับ: FR-AUTH-01, CON-CACHE-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง FR-AUTH-01 แทน)
- ไฟล์ที่แตะ: `backend/app/api/auth.py`, `backend/tests/test_auth_session.py`
- ต้องทำหลัง: T-02
- เสร็จเมื่อ: POST `/auth/refresh` ออก session ใหม่เมื่อส่ง refresh token ที่ยังใช้ได้ และปฏิเสธเมื่อไม่ใช้ได้
- สถานะ: รอ Q2; รอการตัดสินใจทีม: วิธีรัน Redis สำหรับ test

### T-04 วัดอัตราการหลุดของ session
- รองรับ: NFR-REL-01, CON-CACHE-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง NFR-REL-01 แทน)
- ไฟล์ที่แตะ: `backend/tests/test_auth_reliability.py`
- ต้องทำหลัง: T-03
- เสร็จเมื่อ: สคริปต์นับ session ที่หลุดในช่วงทดสอบและบันทึกผลได้ (ยังไม่มีเกณฑ์ผ่าน/ไม่ผ่าน)
- สถานะ: รอ Q2

### T-05 สร้างหน้าจอเข้าใช้งานต่อเนื่องด้วยข้อมูลจำลอง
- รองรับ: FR-AUTH-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง FR-AUTH-01 แทน)
- ไฟล์ที่แตะ: `frontend/src/pages/AutoLogin.jsx`, `frontend/src/api/mockAuth.js`
- ต้องทำหลัง: โครงโปรเจกต์ (ดูหมายเหตุ 001) (ใช้ข้อมูลจำลองตามสัญญา API ใน plan.md ข้อ 4 ไม่รอ T-03)
- เสร็จเมื่อ: หน้าจอแสดงสถานะ session จาก `mockAuth.js` ได้
- สถานะ: รอ Q2; รอการตัดสินใจทีม: โครงโปรเจกต์ (ดูหมายเหตุ 001); รอการตัดสินใจทีม: ยืนยันข้อเสนอ UI เข้าใช้งานต่อเนื่อง (ดู Assumptions)
