# Feature: LINE Bot
Spec ID: FR-LINE-01, FR-LINE-02, IF-LINE-01 | Source: `req/refine-req.md` (v5) | Status: Draft v1 | อัปเดต: 4 ตุลาคม 2569

## Goal
สมาชิกดูข้อมูลและสถานะการจองคลาสของตนเอง และถามคำถามทั่วไปเกี่ยวกับยิมผ่าน LINE Bot

## Scope
### In scope
- FR-LINE-01 สมาชิกเรียกดูข้อมูลและสถานะการจองคลาสของตนเองผ่าน LINE Bot
- FR-LINE-02 ระบบตอบคำถามทั่วไปที่พบบ่อยเกี่ยวกับยิมและการใช้งานผ่าน LINE Bot อัตโนมัติ
- IF-LINE-01 เชื่อมต่อ LINE Messaging API
### Out of scope
- ตัดออกทั้งระบบ (refine-req §2.1–2.2): POS และการขายหน้าร้าน; เครื่องสแกนเวลาและการซิงค์ HR; Data Privacy & Encryption (TLS 1.3, AES-256, PDPA); Nutrition (FR-NUT-01, IF-NUT-01); ระบบเช็กสถานะเครื่องเล่นและคิวเครื่องเล่น (Q10)

## Constraints
- IF-LINE-01 เชื่อมต่อ LINE Messaging API เพื่อให้บริการ LINE Bot และดึงข้อมูลการจอง

## Requirements (ยอมรับแล้ว)
| ID | ข้อกำหนด |
|---|---|
| FR-LINE-01 | **LINE Bot ดึงข้อมูลการจองคลาส**: สมาชิกเรียกดูข้อมูลและสถานะการจองคลาสของตนเองผ่าน LINE Bot ได้ |
| FR-LINE-02 | **LINE Bot ตอบคำถามเบื้องต้น (FAQ)**: ระบบตอบคำถามทั่วไปที่พบบ่อยเกี่ยวกับยิมและการใช้งานผ่าน LINE Bot อัตโนมัติ |

## Assumptions & Open Questions
- **Q5** ผู้ใช้ยืนยันตัวตนบน LINE Bot อย่างไรเพื่อผูกกับข้อมูลการจองของตน (ยังไม่มีคำตอบ ค่าเดา: ผูกบัญชีครั้งแรกด้วยการล็อกอิน ผู้ตอบที่น่าจะได้: ทีมพัฒนาระบบ) เกี่ยวกับ FR-LINE-01, IF-LINE-01 — การผูกบัญชีย้ายมาจาก Out of scope เพราะยังไม่ได้ตัดสิน
- ยังไม่มีหมายเลข Q: พฤติกรรมเมื่อ LINE Messaging API ไม่ตอบสนอง (IF-LINE-01 ไม่ได้ระบุ)
- ยังไม่มีหมายเลข Q: ใครเป็นเจ้าของข้อมูลสมาชิก เพราะการผูกบัญชี LINE ต้องอ้างถึงสมาชิก
- ยังไม่มีหมายเลข Q: ชุดคำถามที่พบบ่อย (FAQ) และคำตอบที่ระบบจะใช้ ใครเป็นผู้จัดทำ (ทีมเลือกเอง)
- คำถามข้อเสนอ UI (ไม่มี ID): ผู้ใช้ควรเรียกดูคำถามที่พบบ่อยได้จากในห้องแชต LINE ใช่หรือไม่? (เกี่ยวข้องกับ FR-LINE-02; ยังไม่มีหมายเลข Q)
- คำถามข้อเสนอ UI (ไม่มี ID): คำตอบเรื่องการจองควรแสดงคลาส วันเวลา และสถานะการจองของผู้ใช้คนนั้นใช่หรือไม่? รูปแบบข้อความ (เช่น Rich Menu / Flex Message) ทีมเลือกเอง (เกี่ยวข้องกับ Q5)
