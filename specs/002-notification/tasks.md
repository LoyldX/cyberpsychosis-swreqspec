### T-01 สร้างโครงข้อมูลข้อความแจ้งเตือน
- รองรับ: FR-NOTI-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง FR-NOTI-01 แทน)
- ไฟล์ที่แตะ: `backend/app/models/notification.py`, `backend/tests/test_notification.py`
- ต้องทำหลัง: โครงโปรเจกต์ (ดูหมายเหตุ 001)
- เสร็จเมื่อ: model Notification message มีฟิลด์เนื้อหา ประเภท ผู้รับ และสถานะการส่ง และ import ได้
- สถานะ: รอการตัดสินใจทีม: โครงโปรเจกต์ (ดูหมายเหตุ 001); รอการตัดสินใจทีม: เจ้าของข้อมูลสมาชิก (ผู้รับข้อความ)

### T-02 สร้าง endpoint ส่งข้อความ
- รองรับ: FR-NOTI-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง FR-NOTI-01 แทน)
- ไฟล์ที่แตะ: `backend/app/api/notifications.py`, `backend/tests/test_notification.py`
- ต้องทำหลัง: T-01

- สถานะ: รอ Q9; รอการตัดสินใจทีม: ผู้รับกลุ่มและรอบเวลาส่ง; รอการตัดสินใจทีม: ผู้มีสิทธิ์สร้างข่าวสาร (การล็อกอินเจ้าหน้าที่)

### T-03 เลือกและเชื่อมบริการ push
- รองรับ: FR-NOTI-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง FR-NOTI-01 แทน)

- ต้องทำหลัง: T-02; บริการ push ที่ทีมเลือก (ดูหมายเหตุ 002)

- สถานะ: รอการตัดสินใจทีม: บริการ push สำหรับแอปสมาชิก (ทีมเลือกเอง ไม่ได้มาจาก spec)
