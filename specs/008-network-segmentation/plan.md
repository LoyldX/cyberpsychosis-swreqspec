# แผน: Network Segmentation

## 1. สรุปแนวทาง

ระบบเครือข่ายจะแยก Wi-Fi ของพนักงานและสมาชิกตาม NFR-SEC-01
การแยกจะใช้ VLAN ตามข้อกำหนดใน spec
แผนนี้ครอบคลุมเฉพาะการแยกเครือข่าย ไม่เพิ่มกฎความปลอดภัยอื่น
รายละเอียดอุปกรณ์และ topology ยังไม่ระบุใน source
จึงต้องยืนยันรายละเอียดโครงสร้างก่อนติดตั้งจริง

## 2. เทคโนโลยีที่ใช้

| สิ่งที่เลือก | มาจาก | หมายเหตุ |
|---|---|---|
| VLAN | NFR-SEC-01 | เป็นข้อกำหนดโดยตรง |
| อุปกรณ์เครือข่าย | ทีมเลือกเอง ไม่ได้มาจาก spec | ยังไม่ระบุรุ่นหรือผู้ผลิต |

## 3. โมเดลข้อมูล

ไม่มี entity ของ application ใน spec นี้

## 4. API / หน้าจอ

ไม่มี API หรือหน้าจอของ application ใน spec นี้

## 5. ตารางตรวจ Constraints

ไม่มี CON, DOM หรือ IF ใน spec นี้; NFR-SEC-01 ถูกตรวจใน Quality Requirements

## 6. แผนทดสอบจาก Acceptance Criteria

ยังไม่มี Acceptance Criteria ใน spec จึงยังสร้าง test ที่อ้าง AC ไม่ได้

## 7. ลำดับงาน

1. ระบุเครือข่ายพนักงานและสมาชิกตาม NFR-SEC-01
2. ออกแบบ VLAN แยกสองกลุ่มตาม NFR-SEC-01
3. เลือกอุปกรณ์โดยทีม เพราะ source ไม่ได้ระบุ
4. ตรวจการแยกการเชื่อมต่อระหว่าง VLAN
5. เพิ่ม Acceptance Criteria ก่อนทดสอบจริง

## 8. สิ่งที่ยังไม่ทำ

ไม่มี Open Question เฉพาะฟีเจอร์นี้ใน spec แต่รายละเอียดอุปกรณ์และ topology ที่ source ไม่ได้ระบุจะยังไม่สร้างจนกว่าจะได้คำตอบจากทีม
