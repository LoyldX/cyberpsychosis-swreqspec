# แผน: Network Segmentation
Spec: `specs/008-network-segmentation/spec.md` (Draft v2 — ยังไม่ผ่าน clarify) | สร้างเมื่อ 4 ตุลาคม 2569 | หน้านี้เป็นผลลัพธ์ที่ AI ร่าง คนตรวจต้องยืนยัน

## 1. สรุปแนวทาง
ระบบเครือข่ายแยก Wi-Fi ของพนักงานและของสมาชิกด้วย VLAN ตาม NFR-SEC-01
แผนนี้ครอบคลุมเฉพาะการแยกเครือข่ายและการทดสอบว่าเข้าข้ามกันไม่ได้ ไม่เพิ่มกฎความปลอดภัยอื่น
ช่วง VLAN อุปกรณ์ และ topology ไม่ได้ระบุใน refine-req จึงเป็นการตัดสินใจของทีม (ไม่ได้มาจาก spec)
spec นี้ไม่มี application entity หรือ API จึงไม่มีโค้ดให้สร้าง

## 2. เทคโนโลยีที่ใช้
| สิ่งที่เลือก | มาจาก | หมายเหตุ |
|---|---|---|
| VLAN | NFR-SEC-01 | เป็นข้อกำหนดโดยตรง |
| อุปกรณ์เครือข่าย (รุ่นและผู้ผลิต) | ทีมเลือกเอง ไม่ได้มาจาก spec | ยังไม่ระบุ |

## 3. โมเดลข้อมูล
ไม่มี entity ของ application ใน spec นี้

## 4. API / หน้าจอ
ไม่มี API หรือหน้าจอของ application ใน spec นี้

## 5. ตารางตรวจ Constraints
| Constraint ID | ถูกนำไปใช้ที่ไหนใน plan | สถานะ |
|---|---|---|
| — | ไม่มี CON, DOM หรือ IF ใน spec นี้ | ไม่มีรายการให้ตรวจ (NFR-SEC-01 อยู่ใน Quality Requirements ตรวจที่ข้อ 6) |

## 6. แผนทดสอบจาก Acceptance Criteria
ทุก AC เป็น Candidate (ยังไม่ผ่านการยืนยันจากทีม) ทดสอบด้วยการทดสอบเครือข่ายเอง ไม่ใช่ unit test ของโค้ด

| AC ID | ชื่อ test | ทดสอบอย่างไร |
|---|---|---|
| AC-NET-01 (Candidate) | `test_AC_NET_01_member_wifi_cannot_reach_staff_vlan` | เชื่อมอุปกรณ์กับ Wi-Fi สมาชิกแล้วพยายามเข้าถึงที่อยู่ในเครือข่ายพนักงาน ตรวจว่าเข้าไม่ได้ |
| AC-NET-02 (Candidate) | `test_AC_NET_02_staff_and_member_wifi_separated_by_vlan` | ตรวจการตั้งค่าอุปกรณ์ว่าแต่ละ Wi-Fi อยู่คนละ VLAN (ช่วง VLAN = ทีมเลือกเอง) |

## 7. ลำดับงาน
1. ระบุเครือข่ายพนักงานและสมาชิกที่ต้องแยก (NFR-SEC-01, ทีมตัดสินใจ)
2. ทีมกำหนดช่วง VLAN และอุปกรณ์ที่ใช้ (ไม่มีใน spec)
3. ตั้งค่า VLAN แยกสองกลุ่ม (NFR-SEC-01, AC-NET-02)
4. ตั้งกฎไม่ให้ Wi-Fi สมาชิกเข้าเครือข่ายพนักงาน (NFR-SEC-01)
5. ทดสอบการเข้าข้าม VLAN (AC-NET-01)

## 8. สิ่งที่ยังไม่ทำ
- ไม่มี Open Question เฉพาะฟีเจอร์นี้ในหัวข้อ 8.2 ของ refine-req
- ยังไม่มีหมายเลข Q: ช่วง VLAN และอุปกรณ์เครือข่าย เป็นการตัดสินใจของทีม จะยังไม่ตั้งค่าจนกว่าทีมจะระบุ
- หมายเหตุ NS-2 (ไม่ใช่ requirement): เรื่องแอร์และอุณหภูมิเป็นสภาพแวดล้อม ไม่อยู่ในแผนนี้
