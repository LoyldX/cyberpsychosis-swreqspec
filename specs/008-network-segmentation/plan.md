# แผน: Network Segmentation
Spec: `specs/008-network-segmentation/spec.md` (Draft v1) | สร้างเมื่อ 4 ตุลาคม 2569 | หน้านี้เป็นผลลัพธ์ที่ AI ร่าง คนตรวจต้องยืนยัน

## 1. สรุปแนวทาง
ระบบเครือข่ายแยก Wi-Fi ของพนักงานและของสมาชิกด้วย VLAN ตาม NFR-SEC-01
แผนนี้ครอบคลุมเฉพาะการแยกเครือข่ายและการทดสอบว่าเข้าข้ามกันไม่ได้ ไม่เพิ่มกฎความปลอดภัยอื่น
ช่วง VLAN อุปกรณ์ และ topology ไม่ได้ระบุใน refine-req จึงเป็นการตัดสินใจของทีม (ไม่ได้มาจาก spec)
spec นี้ไม่มี application entity หรือ API จึงไม่มีโค้ดให้สร้าง งานทั้งหมดเป็นงานตั้งค่าเครือข่ายของทีม

## 2. เทคโนโลยีที่ใช้
| สิ่งที่เลือก | มาจาก | หมายเหตุ |
|---|---|---|
| VLAN | NFR-SEC-01 | เป็นข้อกำหนดโดยตรง |
| อุปกรณ์เครือข่าย (รุ่นและผู้ผลิต) | ทีมเลือกเอง ไม่ได้มาจาก spec | ยังไม่ระบุ |

## 3. โมเดลข้อมูล
ไม่มี entity ของ application ใน spec นี้

## 4. API / หน้าจอ
ไม่มี API หรือหน้าจอของ application ใน spec นี้

## 5. ตารางตรวจ Constraints
| Constraint ID | ถูกนำไปใช้ที่ไหนใน plan | สถานะ |
|---|---|---|
| — | ไม่มี CON, DOM หรือ IF ใน spec นี้ | ไม่มีรายการให้ตรวจ (NFR-SEC-01 ตรวจในข้อ 6 และ 7) |

## 6. แผนทดสอบ
ยังไม่มี AC ใน spec รอทีมกำหนด AC ทดสอบด้วยการทดสอบเครือข่ายโดยทีม ไม่ใช่ unit test ของโค้ด

สมมติฐาน: จนกว่าทีมจะกำหนด AC ให้อ้าง NFR-SEC-01 เป็นชื่อหัวข้อการทดสอบ และไม่อ้าง AC ใด

## 7. ลำดับงาน
1. T-01 กำหนดช่วง VLAN ของ Wi-Fi พนักงานและ Wi-Fi สมาชิก (รองรับ: NFR-SEC-01; สถานะ: รอการตัดสินใจทีม: ช่วง VLAN ของ Wi-Fi พนักงานและ Wi-Fi สมาชิก (ดูหมายเหตุ 008))
2. T-02 ตั้งค่า VLAN แยก Wi-Fi พนักงานและ Wi-Fi สมาชิก (รองรับ: NFR-SEC-01; สถานะ: รอการตัดสินใจทีม: อุปกรณ์เครือข่ายที่ใช้ (รุ่นและผู้ผลิต) (ดูหมายเหตุ 008))
3. T-03 ตั้งกฎไม่ให้ Wi-Fi สมาชิกเข้าเครือข่ายพนักงาน (รองรับ: NFR-SEC-01; สถานะ: รอการตัดสินใจทีม: อุปกรณ์เครือข่ายที่ใช้ (รุ่นและผู้ผลิต) (ดูหมายเหตุ 008); รอการตัดสินใจทีม: ตำแหน่งบันทึกการตั้งค่า (ดูหมายเหตุ 008))
4. T-04 ทดสอบการเข้าข้าม VLAN จาก Wi-Fi สมาชิก (รองรับ: NFR-SEC-01; สถานะ: รอการตัดสินใจทีม: ช่วง VLAN และอุปกรณ์ที่ใช้ (ผลของ T-01 ถึง T-03 ยังไม่มี))

## 8. สิ่งที่ยังไม่ทำ
- ยังไม่มีหมายเลข Q: ช่วง VLAN ของเครือข่ายทั้งสอง รอการตัดสินใจทีม ยังไม่ตั้งค่าจนกว่าทีมจะระบุ
- ยังไม่มีหมายเลข Q: อุปกรณ์เครือข่ายที่ใช้ รอการตัดสินใจทีม ยังไม่ตั้งค่าจนกว่าทีมจะระบุ
- ยังไม่มีหมายเลข Q: ตำแหน่งบันทึกการตั้งค่า รอการตัดสินใจทีม
