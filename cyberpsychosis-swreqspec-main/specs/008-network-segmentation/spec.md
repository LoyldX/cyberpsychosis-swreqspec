# Feature: Network Segmentation
Spec ID: NFR-SEC-01 | Source: `docs/srs/srs.md` (v5) | Status: Draft v1 | อัปเดต: 4 ตุลาคม 2569

## Goal
ระบบต้องแยกเครือข่าย Wi-Fi ของพนักงานและสมาชิกออกจากกันอย่างชัดเจน เพื่อป้องกันการเข้าถึงข้อมูลหรือทรัพยากรที่ไม่ควรใช้ร่วมกันและลดความเสี่ยงจากการโจรกรรมข้อมูล

## Scope
### In scope
- NFR-SEC-01 แยกเครือข่าย Wi-Fi ของพนักงานและ Wi-Fi สมาชิกออกจากกันด้วยการแบ่งโครงสร้างเครือข่ายตามบทบาทหรือกลุ่มผู้ใช้งาน
### Out of scope
- ตัดออกทั้งระบบ (refine-req §2.1–2.2): POS และการขายหน้าร้าน; เครื่องสแกนเวลาและการซิงค์ HR; Data Privacy & Encryption (TLS 1.3, AES-256, PDPA); Nutrition (FR-NUT-01, IF-NUT-01); ระบบเช็กสถานะเครื่องเล่นและคิวเครื่องเล่น (Q10)

## Constraints
- Spec นี้ไม่ได้ระบุชนิดของเครือข่ายหรือเทคโนโลยีเฉพาะ เช่น VLAN, ACL หรือ segmentation แบบอื่น จึงต้องคงไว้เฉพาะข้อกำหนดด้านความปลอดภัยที่ชัดเจน
- ไม่ได้กำหนดว่าพนักงานและสมาชิกต้องเข้าถึงทรัพยากรร่วมกันหรือแยกกันอย่างไรในแง่ application layer; ข้อกำหนดนี้เน้นที่การแยกลักษณะช่องทางเครือข่ายเท่านั้น

## Assumptions & Open Questions
- ยังไม่มีหมายเลข Q: ช่วง VLAN หรือโครงสร้างแบ่งเครือข่ายที่ใช้สำหรับ Wi-Fi พนักงานและ Wi-Fi สมาชิก (เป็นการตัดสินใจของทีม ไม่ได้มาจาก spec)
- ยังไม่มีหมายเลข Q: อุปกรณ์เครือข่ายที่ใช้ รุ่นและผู้ผลิต รวมถึง topology (เป็นการตัดสินใจของทีม ไม่ได้มาจาก spec)
- ยังไม่มีหมายเลข Q: ตำแหน่งที่บันทึกการตั้งค่าเครือข่าย (spec นี้ไม่มี application code)
- หมายเหตุ: spec นี้ไม่มี application entity หรือ API จึงไม่มีโค้ดให้สร้าง
