- รอการตัดสินใจทีม: ช่วง VLAN ของ Wi-Fi พนักงานและ Wi-Fi สมาชิก (T-01 รอเรื่องนี้)
- รอการตัดสินใจทีม: อุปกรณ์เครือข่ายที่ใช้ (รุ่นและผู้ผลิต) (T-02 และ T-03 รอเรื่องนี้)
- รอการตัดสินใจทีม: ตำแหน่งบันทึกการตั้งค่า (T-03 รอเรื่องนี้)

## รายการ task

### T-01 กำหนดช่วง VLAN ของ Wi-Fi พนักงานและ Wi-Fi สมาชิก
- รองรับ: NFR-SEC-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง NFR-SEC-01 แทน)
- ไฟล์ที่แตะ: ไม่มีไฟล์โค้ด เป็นงาน config ของทีม ผู้ทำ: ทีม
- ต้องทำหลัง: ไม่มี
- เสร็จเมื่อ: ทีมบันทึกช่วง VLAN ของเครือข่ายทั้งสองเป็นลายลักษณ์อักษรแล้ว
- สถานะ: รอการตัดสินใจทีม: ช่วง VLAN ของ Wi-Fi พนักงานและ Wi-Fi สมาชิก (ดูหมายเหตุ 008)

### T-02 ตั้งค่า VLAN แยก Wi-Fi พนักงานและ Wi-Fi สมาชิก
- รองรับ: NFR-SEC-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง NFR-SEC-01 แทน)
- ไฟล์ที่แตะ: ไม่มีไฟล์โค้ด เป็นงาน config ของทีม ผู้ทำ: ทีม
- ต้องทำหลัง: T-01
- เสร็จเมื่อ: ทีมบันทึกการตั้งค่าที่แสดงว่าสองเครือข่ายอยู่คนละ VLAN แล้ว
- สถานะ: รอการตัดสินใจทีม: อุปกรณ์เครือข่ายที่ใช้ (รุ่นและผู้ผลิต) (ดูหมายเหตุ 008)

### T-03 ตั้งกฎไม่ให้ Wi-Fi สมาชิกเข้าเครือข่ายพนักงาน
- รองรับ: NFR-SEC-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง NFR-SEC-01 แทน)
- ไฟล์ที่แตะ: ไม่มีไฟล์โค้ด เป็นงาน config ของทีม ผู้ทำ: ทีม
- ต้องทำหลัง: T-02
- เสร็จเมื่อ: กฎถูกตั้งและบันทึกไว้
- สถานะ: รอการตัดสินใจทีม: อุปกรณ์เครือข่ายที่ใช้ (รุ่นและผู้ผลิต) (ดูหมายเหตุ 008); รอการตัดสินใจทีม: ตำแหน่งบันทึกการตั้งค่า (ดูหมายเหตุ 008)

### T-04 ทดสอบการเข้าข้าม VLAN จาก Wi-Fi สมาชิก
- รองรับ: NFR-SEC-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง NFR-SEC-01 แทน)
- ไฟล์ที่แตะ: ไม่มีไฟล์โค้ด เป็นงาน config ของทีม ผู้ทำ: ทีม (บันทึกผลทดสอบในรายงานของทีม)
- ต้องทำหลัง: T-03
- เสร็จเมื่อ: อุปกรณ์ที่เชื่อม Wi-Fi สมาชิกเข้าถึงที่อยู่ในเครือข่ายพนักงานไม่ได้ และบันทึกผลแล้ว
- สถานะ: รอการตัดสินใจทีม: ช่วง VLAN และอุปกรณ์ที่ใช้ (ผลของ T-01 ถึง T-03 ยังไม่มี)
