## รายการ task

### T-01 สร้าง model และ repository interface ของ Trainer roster
- รองรับ: FR-ROST-01, CON-DB-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง FR-ROST-01 แทน)
- ไฟล์ที่แตะ: `backend/app/models/trainer_roster.py`, `backend/app/repositories/roster_repository.py`
- ต้องทำหลัง: โครงโปรเจกต์ (ดูหมายเหตุ 001)
- เสร็จเมื่อ: model มีฟิลด์เทรนเนอร์ ช่วงเวลาเข้างาน และช่วงเวลาสอน และ interface import ได้
- สถานะ: รอการตัดสินใจทีม: โครงโปรเจกต์ (ดูหมายเหตุ 001); รอการตัดสินใจทีม: รูปแบบช่วงเวลาและตารางงาน (ยังไม่มีหมายเลข Q)

### T-02 สร้าง GET/PUT ตารางงานเทรนเนอร์ด้วย fake repository
- รองรับ: FR-ROST-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง FR-ROST-01 แทน)
- ไฟล์ที่แตะ: `backend/app/api/roster.py`, `backend/tests/test_trainer_roster.py`, `backend/tests/fake_roster_repository.py`
- ต้องทำหลัง: T-01
- เสร็จเมื่อ: GET และ PUT `/trainers/{trainerId}/roster` อ่านค่าที่บันทึกกลับได้ผ่าน fake repository
- สถานะ: รอการตัดสินใจทีม: การล็อกอินและสิทธิ์ของเจ้าหน้าที่/ผู้จัดการ; รอการตัดสินใจทีม: รูปแบบช่วงเวลาและตารางงาน
