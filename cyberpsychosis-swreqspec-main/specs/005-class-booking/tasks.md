### T-04 สร้าง model Booking และ POST การจองคลาส
- รองรับ: FR-BKG-01, FR-BKG-02, DOM-BKG-01
- ตรวจด้วย: ยังไม่มี AC รอทีมกำหนด (อ้าง FR-BKG-01 แทน)
- ไฟล์ที่แตะ: `backend/app/models/class_booking.py` (เพิ่ม model Booking), `backend/app/api/bookings.py`, `backend/tests/test_class_booking.py`
